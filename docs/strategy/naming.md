# Naming decision: Loomplane

September 18, 2026. **Use Loomplane for this release.** It is readable infrastructure terminology and fits the context coordination thesis. This is a practical working-name decision based on a bounded public search; it is not trademark clearance or assurance of exclusive rights.

The earlier name, Weft, creates immediate confusion. [spranab/weft](https://github.com/spranab/weft) is already an agent execution ledger with provenance, MCP, and stale-read checks. [Weft CLI](https://weftcli.com/agents/) is an AI coding workflow. [stevekinney/weft](https://github.com/stevekinney/weft) documents binaries named `weft` and `weft-mcp`. These are concrete discoverability and command-name collisions, independent of any legal question.

## Candidate check

| Candidate     | Current primary/public evidence                                                                                                                                                                                                                                                      | Decision                                                                                                       |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| Pactline      | [pactline.io](https://pactline.io/) already markets approval and evidence infrastructure for AI actions.                                                                                                                                                                             | Reject: directly adjacent software brand.                                                                      |
| Pactrail      | [AKMessi/pactrail](https://github.com/AKMessi/pactrail) is a coding-agent harness; GitHub search also found a peer-agent coordination project.                                                                                                                                       | Reject: exact same-category collision.                                                                         |
| Kinset        | [Kinset](https://www.kinset.com/legal/terms-of-service/) identifies an existing software infrastructure service for traceability.                                                                                                                                                    | Reject: existing software brand.                                                                               |
| Pactloom      | [Pactloom](https://getpactloom.com/) markets AI contract intelligence.                                                                                                                                                                                                               | Reject: occupied AI product name.                                                                              |
| Revloom       | [ReVloom](https://www.revloomapp.com/) markets automated review management.                                                                                                                                                                                                          | Reject: occupied software product name.                                                                        |
| **Loomplane** | Exact quoted web search found no identifiable product; the [GitHub repository-name search](https://api.github.com/search/repositories?q=loomplane%20in%3Aname) returned HTTP 200 and zero results; [npm’s package endpoint](https://registry.npmjs.org/loomplane) returned HTTP 404. | **Best candidate from this check.** Negative search results are limited evidence, not guaranteed availability. |

All six exact unscoped npm package endpoints returned 404 during this check. That did not make the five occupied brands suitable. GitHub repository-name search counts were Pactline 7, Pactrail 4, Kinset 6, Loomplane 0, Pactloom 0, and Revloom 1; substring matches and indexing mean counts are not counts of competing products. Queries used the official GitHub API and npm registry; results can change immediately.

## Release implication

Use `Loomplane`, package/CLI `loomplane`, repository [davidbergman256/loomplane](https://github.com/davidbergman256/loomplane), environment prefix `LOOMPLANE_`, and local directory `.loomplane` consistently. Root implementation owns the mechanical migration. Avoid mixing old example commands with new binaries, and document any migration from existing local data. A declared package name does not reserve npm ownership; verify again when actually publishing. No domain, package registration, trademark filing, or external outreach was performed for this naming check.
